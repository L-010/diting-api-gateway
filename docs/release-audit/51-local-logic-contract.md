# 第六阶段：本地逻辑行为契约

## 范围与证据规则

- 范围是当前代码的用户级资源隔离；没有把用户标签或测试数据当成 tenant/organization 实现。
- 证据来自 `backend/app`、`backend/tests`、`frontend/app`、`frontend/components` 与 `frontend/lib`；所有验证使用临时 SQLite、Mock SMTP 或 Mock HTTP 上游。
- “业务语义未知”表示代码无法证明的产品规则，不将其当作代码已实现或测试失败。

| 功能 | 代码当前行为与证据位置 | 前置条件 | 成功结果 | 拒绝结果 | 不变量与边界 | 业务语义未知 |
|---|---|---|---|---|---|---|
| 注册、验证与审批 | `routers/auth.py:register` 创建 `pending`、`is_active=False` 用户、单次验证令牌和 Outbox；`routers/admin.py:approve_user/reject_user` 完成审批；`services/user_lifecycle.py` 使同用途旧令牌失效。 | SMTP 已配置；用户名、邮箱、密码通过校验。 | 注册 201，验证后仍待审批；管理员批准后才可登录。 | SMTP 未配置 503；重复用户名/邮箱 409；令牌无效、过期或重复使用 422；拒绝用户登录 403。 | 用户名先去空白并按小写规范键唯一；邮箱小写；注册写入失败不会留下角色、令牌或 Outbox 部分数据。边界含 Unicode、控制字符、12 至 256 位密码。 | 审批是否必须等待邮箱验证、拒绝后是否允许重新申请、用户名展示大小写规则未定义。 |
| 登录、退出、改密与会话失效 | `routers/auth.py:login/logout/change_password/reset_password`；`routers/deps.py:get_current_user` 校验 JWT 中 `session_version`、审批、停用与锁定；`services/security.py:create_session_token`。 | 已批准、启用、已验证且未锁定的账号；写操作带双提交 CSRF。 | 登录发出 HttpOnly 会话和 CSRF Cookie；登出、改密、管理员重置、找回重置后旧会话失效。 | 无效凭据 401；锁定 423；待审批、拒绝、未验证或停用 403；缺少/错误 CSRF 403。 | 密码变更递增 `session_version`；旧 Cookie 不能继续访问；错误响应不含密码或 JWT。 | 登录失败计数的产品阈值、临时密码的到期策略未定义。 |
| user/admin 边界 | `routers/deps.py:require_not_password_change/require_admin`，各 `/api/admin/*` 路由注入 `require_admin`；门户路由注入普通会话依赖。 | 有效会话；管理员有 `user_roles.admin`。 | 管理员可进入管理接口；普通用户访问自己的门户数据。 | 匿名 401；普通用户访问管理 API 403；强制改密账号不能访问普通门户。 | 授权在后端依赖中执行，不依赖前端菜单隐藏。 | 管理员是否可跨越 owner Gateway 路由由代码定义为否，是否符合业务待确认。 |
| 用户级资源与列表过滤 | `services/resource_policies.py:execute_pre_checks/filter_owned_list/execute_post_actions`，`routers/portal.py`、`routers/files.py` 使用 `owner_user_id` 条件。 | 路由为 `owner` 且资源已由成功上游响应登记。 | owner 可读写自己的映射资源；列表只返回其登记 ID；文件、任务、调用记录按用户过滤。 | 其他用户同 ID 返回 404，不暴露资源存在性。 | `ExternalResource(tool_id, kind, upstream_id)` 全局唯一，所有者冲突失败关闭；列表项缺少资源 ID 时 502，不返回未过滤数据。 | 无 tenant/organization 字段；用户级隔离不能证明多租户隔离。 |
| owner/shared/admin_only 策略 | `services/resource_policies.py` 与 `services/gateway_proxy.py:proxy_gateway_request`。`owner` 执行前置归属检查和后置登记，`shared` 仅要求有效 Key，`admin_only` 要求 Key 所属用户具备 admin。 | 已发布、启用的 Gateway 路由及有效 API Key。 | `owner` 只允许所有者；`shared` 允许任意已认证 Key；管理员 Key 可进入 `admin_only`。 | 普通 Key 调用 `admin_only` 403；owner 非所有者 404。 | 静态路径优先于参数路径，避免错误上游路由；策略 JSON 非法或提取失败时失败关闭为 502。 | `shared` 是否应跨用户共享、admin 是否应查看 owner 数据，均未在模型中定义。 |
| API Key 生命周期、scope 与 Gateway | `routers/auth.py:create_user_api_key/disable_user_api_key`，`routers/gateway.py:authenticate_api_key/api_key_allows_tool`。完整 Key 只在创建响应返回，库中只保存哈希。 | 已批准用户、有效会话和 CSRF；Gateway 传入 `X-API-Key`。 | 创建 201；默认 `*` scope；禁用、过期、账号不可用时 Gateway 拒绝；工具 scope 可放行指定工具。 | 缺失/失效/过期 Key 401；scope 不足 403；重复禁用 409。 | 完整 Key 不进入审计或列表；Key 每次调用更新 `last_used_at`。 | 当前用户 UI 和创建 API 只支持全局 `*` Key；细粒度 scope 签发、轮换是否为产品需求未知。 |
| OpenAPI 导入、diff、发布、更新、删除与回滚 | `services/openapi_import.py` 解析并拒绝循环/远程 `$ref`；`routers/admin.py:apply_openapi_document`、`_apply_diff_decision`、`bulk_publish_safe_endpoints`、`publish_endpoint`、`rollback_tool_configuration`。 | admin、CSRF、合法文档；发布前 diff 已决策且访问策略已确认。 | 导入生成批次/diff；确认后批量或单接口发布；配置快照可回滚；上游删除或阻断会停用路由。 | 文档非法 422 且不写入；未决策/未确认策略/冲突路径阻止发布；已发布批次重复确认保持幂等。 | 文档解析或资源策略异常不应留下部分 endpoint/route；阻断 endpoint 立即从数据面撤下。 | 何时接受高风险 diff、上游删除后保留周期、回滚业务影响未定义。 |
| Idempotency-Key | `services/idempotency.py` 与 `services/gateway_proxy.py`。仅要求幂等的 POST/DELETE 建立 `(user,key,route,key_hash)` 唯一记录，保存有限大小加密响应。 | 路由 `require_idempotency_key=True`，Key 格式合法，非流式响应。 | 首次调用占有 `processing`；相同指纹完成后重放响应；确定的上游失败也保存并重放；过期记录可替换。 | 缺少或格式错误 422；同 Key 不同请求 422；处理中 409；无法安全缓存结果 409。 | 同一 Key 不重复转发上游；请求指纹覆盖方法、路由、查询、内容类型、体摘要；超大/流式结果失败关闭。 | 上游已执行但网络结果未知时的业务补偿语义、24 小时保留期是否足够未定义。 |
| 任务与文件 | `services/remote_files.py`、`file_worker.py`、`routers/portal.py`、`routers/files.py`。平台登记远程任务/文件，Worker 轮询、验证、删除；下载先签发短期授权并受并发槽限制。 | 已配置工具存储适配器、资源所有者、可用端点版本。 | 文件元数据登记、状态同步、可下载时授权、删除入队；任务详情优先读平台记录；失败任务可由管理员重新同步。 | 非 owner 404；不可下载/删除 409；上游不可达 502、超时 504、超限 413；文件服务 404 映射 410。 | 任务绑定的存储端点版本不可漂移；Worker 条件更新确保一任务只有一个租约；失败释放租约并指数退避；删除墓碑重新出现时被清除。 | 平台没有任务执行、取消或业务重试命令；任务状态枚举和文件保留的产品规则由上游适配器决定。 |
| 监控与告警 | `routers/admin.py:_monitor_alerts/monitor_metrics/monitor_alerts` 从 `GatewayRequest`、文件同步重试和心跳实时聚合。 | admin、有效窗口参数。 | 返回 Key 失败率、工具 5xx、流量、Worker 离线、同步重试和存储水位告警。 | 匿名/普通用户被拒绝；非法时间范围 422。 | 告警只读派生，不改变调用或文件状态；指标只使用脱敏调用记录。 | 没有持久告警、确认、关闭或非法跳转 API，因此不存在可验证的告警确认状态机。 |
