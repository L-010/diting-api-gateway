## 失败先行证据

| 问题 | 失败测试证据 | 修复后断言 |
|---|---|---|
| 静态路径被参数路径吞掉 | 给数据库结果施加反序后，`test_静态路由优先于参数路由` 失败并选中参数路由。 | 按参数数量和路径长度排序，选择静态路由。 |
| 已删除文件重新出现 | `test_文件重新出现时清除删除墓碑` 失败，`deleted_at` 保留。 | 重登记时清空墓碑。 |
| 用户名大小写并发一致性 | `test_用户名大小写变体不能同时写入数据库` 未抛出 `IntegrityError`。 | `username_key` 唯一，数据库拒绝重复。 |
| Worker 重复消费 | 两线程屏障测试返回两个持有者。 | 条件更新后只返回一个有效 lease。 |
| 负 Content-Length | `test_负数内容长度被拒绝` 未抛异常。 | 服务层返回 400。 |
| 新 migration 的 readiness | 将 readiness fixture 升到新 head 后返回 503。 | 运行时与迁移检查预期同步到 `a2b3c4d5e6f7`。 |

## 隔离变异验证

- 在系统临时目录复制 `backend/app`，仅删除 `get_published_route` 的静态路径优先排序。
- 在候选路由返回顺序反转的隔离情形执行与新增回归等价的断言，得到 `AssertionError`；变异被捕获。
- 当前工作区未被该操作改写，原测试通过。临时副本不含业务数据库或凭证。

## 断言质量复核

- 新增测试同时检查 HTTP/异常状态、响应 code、数据库记录、唯一性、租约/墓碑字段及上游调用次数；没有只断言状态码。
- 授权测试以后端响应、`owner_user_id` 查询和导出/列表内容为准，不以 UI 是否隐藏为准。
- 上游失败测试检查 GatewayRequest/IdempotencyRecord/Outbox/同步任务最终状态，未将 500 当作通过。

## 仍可能漏检的高风险路径

- 真实多进程 SQLite 锁争用、跨主机 Worker 和网络半开连接。
- 真正上游已执行但客户端或 Gateway 在接收响应前中断时的补偿语义。
- 真实浏览器并发点击、页面卸载、下载流取消和移动端布局。
- 旧生产数据存在大小写等价用户名时，新唯一索引 migration 会安全失败，需要人工合并/更名后再升级。
