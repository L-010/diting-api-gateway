# 第七阶段：浏览器 E2E 结果

## 执行环境

- 依赖：`frontend/package.json` 新增开发依赖 `@playwright/test 1.51.1`；Chromium 为 Playwright build `1161`（Chromium `134.0.6998.35`），浏览器仅安装在 `frontend/node_modules/playwright-core/.local-browsers`。
- 命令：`.venv\Scripts\python.exe scripts\release_audit\run_phase7_e2e.py`。
- 隔离方式：脚本为每次运行创建临时 SQLite、随机且仅驻留进程环境的合成密码/API Key、本地 FastAPI、临时 Next 开发服务和本地 HTTP stub；结束时终止服务并删除临时数据库。
- 最终结果：`6 passed`，Chromium 单 worker 串行执行。关键截图位于 `output/playwright/phase7/`，截图中不含完整 Key。

## 已验证通过

| 流程 | 浏览器实际断言 |
|---|---|
| 注册 | 匿名用户填写合成数据提交申请，页面显示成功状态。 |
| 登录、退出与会话 | 普通用户登录到门户；退出后访问门户和管理页均跳转登录页。 |
| API Key | 浏览器创建 Key、一次性展示后关闭、按标签撤销；撤销后的 Gateway 请求为 401。 |
| Gateway | 本地 stub 的正常调用 201；同一 `Idempotency-Key` 重放返回同一 201 响应；stub 500 保持为 500；运行时生成的 scope 不匹配 Key 返回 403。 |
| OpenAPI | 管理员在 UI 中从本地 stub 同步、接受 diff、确认批次并批量发布。 |
| 文件与任务 | 任务页显示合成 failed 任务；文件页显示合成文件，实际下载得到指定文件名，删除请求进入异步删除状态。 |
| 监控、审计与权限 | 管理员可加载监控和审计页；普通用户访问 `/admin` 被后端/路由守卫重定向至门户。 |
| 移动端与返回 | `390x844` 视口加载调用页且文档无横向溢出；浏览器返回后页面仍可见。 |

## 未覆盖或受限

- 已确认但属于功能范围：平台没有“创建/取消/业务重试任务”控制接口；本轮只验证 failed 任务展示及管理员文件同步重试相关后端契约，不能将其称为业务任务重试验证。
- 检查受限：没有为全部页面构造大分页、长文本、接口加载失败和网络中止下载的逐页浏览器矩阵；核心页面已有实际加载/空数据代码路径，但该矩阵仍需持续补充。
- 执行注意：前端 `typegen`、`lint`、`build` 必须串行执行；并行运行会竞争 `.next/types` 生成文件，导致工具链瞬时缺文件。
- `@axe-core/playwright` 未声明，未增加额外无障碍扫描依赖；已保留关键页面截图回归。
- 仍需外部环境验证：真实浏览器下载中断、代理网络、企业 SSO/Cookie 策略及真实设备兼容性。

## 结论

已验证通过核心浏览器工作流；这不是生产浏览器兼容性或真实网络环境验证。
