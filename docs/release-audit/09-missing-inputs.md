# 缺失信息与审计前置条件

| 缺失信息 | 缺失影响 | 建议提供方式 | 未提供时默认处理 |
|---|---|---|---|
| 业务规则与关键流程期望结果 | 无法判断注册审批、Key、工具发布、任务/文件状态是否符合业务 | 提供流程图、验收标准、异常码和成功样例 | 只按代码事实审计，相关结论标为待业务确认 |
| 角色、组织、租户定义 | 无法完成跨用户/跨租户授权矩阵 | 提供角色清单、资源归属规则、组织/租户样例 | 仅使用现有 `user/admin` 和 owner/shared 证据，不推断租户隔离 |
| 测试账号和测试租户 | 无法执行真实权限、浏览器和数据隔离测试 | 提供脱敏、可撤销的 user/admin 账号和隔离租户 | 不执行真实写入或越权测试 |
| 最小测试数据、OpenAPI 文档和文件样本 | 无法验证真实导入、资源策略、文件清单、大小和清理 | 提供专用 fixture、样本文档、可删除上游资源 | 继续使用单元/Mock 数据，真实链路标待验证 |
| 生产部署参数 | 无法确认进程数、反向代理、TLS、端口、数据库、日志和 worker 拓扑 | 提供部署清单、容器/服务单元、网络图和回滚方案 | 不判定生产可上线；现有开发脚本仅作本地参考 |
| 性能目标与容量模型 | 无法判断 SQLite/限流/文件并发是否满足上线 | 提供 QPS、并发、p95/p99、文件大小、增长率和 SLO | 不执行高负载测试，不给出通过结论 |
| 第三方测试凭证与允许范围 | 无法验证 tomoDD、SMTP、其它工具上游 | 提供短期最小权限凭证、白名单、只读/写入边界和清理承诺 | 不调用真实第三方；环境变量只记录存在性 |
| 数据保留、删除和合规要求 | 无法确认 90 天调用日志、文件保留、账号删除是否合规 | 提供分类保留表、删除 SLA、备份/恢复要求 | 记录代码默认值，不视为合规结论 |
| 允许执行的测试范围 | 可能误触发真实任务、邮件、文件删除或上游写操作 | 提供明确允许/禁止端点和时间窗口 | 仅执行本地只读检查、Mock 测试和临时数据库测试 |
| 不允许触碰的数据/接口 | 无法界定审计安全边界 | 提供 URL、表、用户、文件和字段黑名单 | 不读取敏感内容，不执行外部写操作 |
| 生产密钥轮换和凭证管理方案 | 无法验证 Fernet、SMTP、API Key pepper 的部署与轮换 | 提供 Secret Manager、轮换周期、应急吊销和审计方式 | 只确认代码字段/环境变量名，不记录或测试真实值 |
| CI/CD 与发布门禁 | 无法确认测试、迁移、构建和回滚是否自动执行 | 提供流水线配置、制品版本、审批和回滚记录 | 视为未发现自动化门禁，不推断不存在外部流水线 |
| 监控、告警和值班响应 | 无法判断 `/monitor/*` 指标是否接入生产告警 | 提供指标接收端、阈值、通知渠道、值班手册 | 仅记录本地 SQLite 计算逻辑，生产告警标待确认 |

## 前置条件优先级

1. 上线前必须先补齐生产启动/部署参数、数据库迁移基线、关键角色和授权规则。
2. 若 tomoDD、SMTP 或文件能力属于上线范围，必须提供专用测试凭证、数据和清理策略。
3. 完整审计阶段需在隔离环境执行浏览器 E2E、越权测试、性能测试、日志脱敏检查和真实依赖验证。
