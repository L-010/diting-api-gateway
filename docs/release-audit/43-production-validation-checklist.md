# 生产验证检查清单

> 状态只能填写“未执行、通过、失败、阻断、待外部输入”。“通过”必须附目标环境证据；本地临时 SQLite、模拟上游和静态阅读不得标记为生产通过。

## 0. 发布门禁前提

- [ ] 当前租户策略已由产品负责人和安全负责人签字，策略版本号：`________`。
- [ ] admin 跨用户/跨租户规则、owner/shared/admin_only 语义已签字。
- [ ] 预计日活、并发、数据量、性能 SLO 已签字。
- [ ] 目标托管、反向代理、TLS、进程管理、日志和监控方案已编号。
- [ ] 非生产 SMTP、TomoDD、文件服务隔离凭证已提供。
- [ ] 备份频率、RPO、RTO、恢复负责人和恢复证据路径已确定。

## 3. 进程、代理与 TLS

- [ ] 生产进程由明确托管器管理，未使用 `--reload`。
- [ ] worker 数量、单实例/多实例策略、优雅停止和启动超时已配置。
- [ ] 进程崩溃会自动拉起并告警；重复启动不会抢占非本服务端口。
- [ ] `/livez`、`/readyz`、`/health` 均按手册验证。
- [ ] 外部入口为 HTTPS，证书链、有效期、主机名、TLS 最低版本已验证。
- [ ] HTTP 只重定向到 HTTPS，不允许 HTTPS 降级；代理不会暴露内部管理端口。
- [ ] 代理已设置连接/读取/上游超时、请求体限制、WebSocket/流式响应策略（如适用）。
- [ ] 真实客户端 IP、请求 ID、访问日志字段和敏感头脱敏规则已核对。

## 4. 核心 API 只读冒烟

- [ ] `GET /livez` 返回 200。
- [ ] `GET /readyz` 返回 200，数据库和迁移检查均为 `ok`。
- [ ] `GET /api/public/config` 返回 200，未泄露密钥或内部地址。
- [ ] `GET /api/public/tools` 返回 200，发布列表与批准清单一致。
- [ ] 未认证 `GET /api/me` 返回 401。
- [ ] 使用最小权限测试主体访问批准的只读 API，状态、响应结构和错误码符合矩阵。
- [ ] 不执行注册、密码重置、上传、删除、文件下载副作用或真实第三方写入。

## 5. Worker 与外部依赖

- [ ] Email worker 存活、Outbox 最终失败可见、重试上限符合批准规则。
- [ ] File worker 心跳、队列积压、同步失败和上游超时均可观测。
- [ ] TomoDD 连通、认证失败、超时、限流和未知结果重试已在隔离环境完成。
- [ ] 真实生产凭证未用于本阶段；非生产凭证的作用域、过期时间和清理责任已记录。

## 6. 备份、恢复和回滚

- [ ] 数据库、文件正文、配置/密钥责任边界已书面确认。
- [ ] 备份完整性校验、临时环境恢复、Alembic head 和业务抽样均有证据。
- [ ] 临时 SQLite 演练未被记录为生产恢复验证。
- [ ] RPO/RTO 已确认且演练达标。
- [ ] 迁移失败决策树、应用版本回滚、流量恢复责任人已在发布窗口值守。

## 7. 关闭条件

本清单所有 P1 必须项均为“通过”且有可复核证据，P2 项有批准的残余风险和截止日期，才可进入最终业务签署。任何租户规则、容量、外部隔离、迁移目标、TLS、备份恢复或告警闭环缺证据，都必须保持“禁止上线”。
