## 解除条件

1. 提供生产启动单元、代理/TLS、密钥和 worker 拓扑，并完成非 reload 启动、readiness、停止和回滚演练。
2. 在目标数据库副本完成从当前版本到 `a1b2c3d4e5f6` 的迁移、备份恢复和失败回滚验证。
3. 明确租户/组织、scope、owner/shared/admin_only 和幂等失败重试规则，运行两租户权限矩阵。
4. 提供隔离 SMTP/tomoDD/文件服务，运行核心浏览器 E2E 和与生产目标匹配的性能基准。
